## 📅 Day-wise Learning Progress

### Day 01 — Basics of JavaScript Functions

* Created simple functions for **adding**, **subtracting**, and **multiplying** two numbers.
* Practiced executing functions and displaying their output using `console.log`.
* File: `day 01/cal.js`

### Day 02 — Different Function Types in JavaScript

* Explored the various ways functions can be created in JavaScript:

  * Arrow functions
  * Function expressions
  * Function declarations
* File: `day 02/function.html`

### Day 03 — Working with `filter()` and `reduce()`

* Applied `filter()` to identify even numbers in an array and then used `reduce()` to calculate their total.
* Used `filter()` with an array of student objects to find students who scored more than 50 marks.
* Files: `day 03/map.html`, `day 03/Filter.html`

### Day 04 — `map()` Method and Promises

* Practiced using `map()` to multiply each element of an array by two.
* Studied **Promises**, including `resolve`, `reject`, `.then()`, and `.catch()`.
* Created a practical promise example based on a pass/fail marks condition using `setTimeout`.
* Files: `day 04/map.html`, `day 04/promis.html`, `day 04/activity.html`

### Day 05 — Working with the Fetch API

* Learned how to retrieve API data using the `fetch()` function along with `async/await`.
* Used `https://jsonplaceholder.typicode.com/posts` as a sample API for testing.
* File: `day 05/fatchdata.html`

### Day 06 — Node.js Modules and REST API Basics

* Understood the difference between **CommonJS** (`require` / `module.exports`) and **ES Modules** (`import` / `export`).
* Created reusable `add`, `sub`, and `mal` functions in a separate file and imported them when required.
* Practiced REST API operations such as GET, POST, PATCH, PUT, and DELETE using a `.rest` file.
* Created a basic Node.js project containing `package.json` and `express`.
* Files: `day 06/1st-node/index.js`, `day 06/1st-node/change.js`, `day 06/test.rest`

### Day 07 — Node.js Built-in Modules: `os` and `fs`

* Worked with the built-in **`os`** module and explored functions such as `uptime()`, `hostname()`, `version()`, and `machine()`.
* Learned how to use the **`fs` (File System)** module for:

  * Reading files synchronously with `readFileSync`.
  * Reading files asynchronously with `readFile`.
  * Adding new data to files using `appendFileSync`.
* File: `day 07/index.js`

### Day 08 — Building a Basic HTTP Server

* Learned how to build a basic Node.js server using the built-in **`http`** module.
* Implemented different routes such as `/home` and `/contact`, along with custom responses for routes that do not exist.
* Practiced starting the server using different ports, including 3000 and 5001.
* File: `day 08/index.js`
